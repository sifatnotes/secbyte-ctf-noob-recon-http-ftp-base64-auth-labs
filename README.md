## Learning Path

A practical progression through this **CTF lab collection**:

1. Start with **Noob Recon Trail** to understand basic reconnaissance.
2. Study **HTTP Header Trail** and learn how web metadata can provide useful clues.
3. Move through the login, authentication, and credential-focused labs.
4. Practice Base64 recognition with the **Base64 Breadcrumbs** challenges.
5. Continue with FTP enumeration and anonymous-share challenges.
6. Finish with **Noob Network Treasure Hunt** to combine network discovery concepts.

## How to Use the Labs

Use these labs only in authorized environments such as CTF platforms, personal virtual machines, or intentionally vulnerable training systems.

For each challenge:

1. Read the lab objective and scope.
2. Identify relevant services or web functionality.
3. Perform authorized reconnaissance.
4. Inspect headers, authentication behavior, files, or encoded content.
5. Document discovered clues and security implications.
6. Connect the findings to defensive security practices.
7. Record lessons learned for future CTF and penetration-testing exercises.

Never test these techniques against systems without explicit authorization.
